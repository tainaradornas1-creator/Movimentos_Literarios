# Instruções para agentes — Movimentos_Literarios

**Produto exclusivo deste repositório:** Atlas Vivo da Literatura Brasileira (`atlas-vivo/`).

Antes de editar, leia `docs/PROJECT.md`, `docs/STATUS.md`, `docs/AI_WORKFLOW.md` e `atlas-vivo/docs/PLANO_CORRECOES_0.2.1.md`.

- Não misturar repositórios/produtos, nem inferir o estado do Git a partir de conversas.
- Editar somente a branch de trabalho adequada e preservar a `main` e a branch publicada.
- Antes de mudar arquitetura, autenticação, armazenamento, critérios pedagógicos ou dependências, solicitar decisão explícita.
- Não publicar/mesclar, alterar configuração de Pages ou enviar dados de estudantes a terceiros sem autorização específica.
- Conservar módulos separados (`src/app.js`, `src/model.js`, `dados/*.json`), com comentários úteis e testes.
- Registrar evidências verificáveis de testes e atualizações no GitHub; não declarar conformidade WCAG sem auditoria.
- Nunca reproduzir conteúdo protegido sem direitos de uso e nunca incluir dados pessoais reais de alunos.
